# リゼ（LIZE-07）— お供・作業Botアドオン

Minecraft 統合版（Bedrock）のアドオンです。言葉で指示すると、採取・クラフト・精錬・建築などを代わりにこなしてくれる、ロボットの相棒「リゼ（LIZE-07）」を追加します。

> 「作業補助機、LIZE-07です。……リゼ、と呼んでください。そのほうが、返事をしやすいので」

## ダウンロード

最新の `Lize-07_v*.mcaddon` をダウンロードしてください。現在の最新版は **v0.5.95** です。

- [Lize-07_v0.5.95.mcaddon をダウンロード](https://github.com/k330labo-blip/lize-07/raw/refs/heads/main/Lize-07_v0.5.95.mcaddon)
- 過去の版は [Tags](https://github.com/k330labo-blip/lize-07/tags) からたどれます（各タグの時点のファイル一式が入っています）

## 導入方法

1. `.mcaddon` ファイルを開くと、Minecraft に自動でインポートされます
2. 遊びたいワールドの「ビヘイビアパック」と「リソースパック」に Lize-07 を適用します
3. ワールドに入り、リモコンアイテムでリゼを呼び出します

他のアドオンは不要で、単体で動作します。

## 使い方

- **召喚**: リモコン（`companion_bot:lize_remote`）を使う
- **メニュー**: リゼを右クリック（しゃがみ＋右クリックでコンテナを開く）
- **文字で指示**: メニューの「文字で指示する」から、またはコマンド `/companion_bot:lize` で指示できます
  - 例：「原木を集めて」「鉄インゴットを作って」「ダイヤモンドを探して」

## できること

- 言葉の指示で採取・伐採・採掘・収穫・回収・納品
- 道具の作成から精錬までを含む、長期タスクの自動実行（例：素手から鉄インゴットまで）
- 鉱石へは螺旋階段状に掘り進み、歩いて帰れる坑道を作る
- ブロックの素材ごとの掘削・破壊・足音などのサウンドと、行動に合わせたアニメーション
- 壊れてしまっても、保持した中身ごとリモコンで再召喚できます
